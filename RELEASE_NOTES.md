# Apex 3 TKL lighting

Version 0.5.0 expands the device command center beyond mice with first-class SteelSeries Apex 3 TKL White support.

- Detects the Apex 3 TKL through its SteelSeries USB identity (`1038:1622`).
- Switches to a dedicated keyboard workspace with eight independent RGB zones, brightness, and rainbow wave controls.
- Adds a high-resolution transparent product image for the white keyboard.
- Shows the keyboard and all detected gaming mice together on Overview when multiple devices are connected.
- Lets you select either device card to open the correct keyboard or mouse control modules without hiding the other hardware.
- Keeps the existing mouse DPI, shortcuts, profiles, diagnostics, and appearance controls intact.

Download **UnnamedEnhancements.exe** below and open it directly. No ZIP extraction is needed for this release asset.
