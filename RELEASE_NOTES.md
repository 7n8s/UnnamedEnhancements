# A calmer, more focused Unnamed

Version 0.3.0 rebuilds the interface around the controls you actually use.

- New charcoal glass design with warm accents, responsive layouts, softer motion, and a compact sidebar.
- Larger DPI editor, interactive button views, redesigned profiles, and a cleaner Serx conversation.
- Appearance settings keep your backgrounds, GIFs, saved profiles, and personal preferences.
- Removed the aim trainer, duplicate utility channels, unverified battery display, ineffective polling controls, and artificial app startup delay.
- Clearer hardware-support boundaries and an explicit keep-running-in-tray option.

Download **UnnamedEnhancements.exe** below, keep it in a permanent folder, and open it directly. No ZIP extraction is needed for this release asset.

Attack Shark X1 hardware DPI support is retained. G304/G305 and Model O Wired remain detection/layout support only. Windows side-button shortcuts work while the app is running; primary-button hardware remapping is not implemented.
